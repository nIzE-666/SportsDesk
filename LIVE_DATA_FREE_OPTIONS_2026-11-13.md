# Бесплатный источник живых матчей для «Сегодня» и «Сейчас идут»

13 ноября 2026 года, дополнение к `LIVE_DATA_SOURCES_RESEARCH_2026-11-12.md` (исследование ChatGPT). Условие пользователя: решение должно быть бесплатным.

## Итог

Для «Сегодня» и «Сейчас идут» предлагается брать данные из **публичного JSON-API LiveScore**. Один запрос отдаёт все матчи местного дня сразу по всем турнирам, причём смещение UTC+9 передаётся в адресе. Второй запрос отдаёт все идущие матчи с минутой и счётом. Запасной источник — **ESPN** (запрос по лиге). Подробности матча (составы, статистика, разбор) остаются на PitchAPI.

Цена: 0. Риск: это неофициальные API, без договора и гарантий. Их могут изменить или закрыть, и, скорее всего, их условия не разрешают такое использование (условия не проверялись). Поэтому нужны запасной источник, бережный опрос и честная отметка «обновлено ЧЧ:ММ».

## Сравнение бесплатных вариантов

| Вариант | Плюсы | Минусы |
|---|---|---|
| **LiveScore (неофициальный JSON)** | Один запрос на весь день с нужным смещением UTC; отдельный запрос всех идущих матчей; есть минута, статус и счёт; покрыты все десять групп турниров | Неофициальный; формат полей сокращённый (`Eps`, `Tr1`, `T1[].Nm`); может измениться без предупреждения |
| FotMob (неофициальный JSON) | Один запрос на день, ответил без особых заголовков | Неофициальный; ранее FotMob вводил подпись запросов, обходить защиту нельзя — если её включат, вариант отпадает |
| ESPN site API (неофициальный JSON) | Стабилен годами, есть `displayClock` | Запрос на каждую лигу (до 10 в минуту во время матчей); ключ даты — не UTC; условия Disney ограничивают автоматический доступ |
| Sports.ru (внутренний GraphQL) | Без ключа, русские названия; проверен 12.11 (пункт 15 в `DEVELOPMENT_PLAN_2026-11-09.md`) | Внутренний API сайта, тот же риск условий; формат запросов надо поддерживать самим |
| football-data.org Free (официальный) | Официальная лицензия с атрибуцией; 10 запросов в минуту | Счёт на бесплатном тарифе с задержкой; нет Лиги Европы, Лиги конференций и MLS |
| PitchAPI (уже подключён) | Официальный ключ, лимитов нет; расписание дня по UTC-датам | По документации нет живого статуса и минуты |
| Без API: расписание PitchAPI + время начала | Ничего нового не нужно | Нет живого счёта и минуты; статус «идёт» угадывается по времени — нечестно по правилам данных |

## Как встроить (шаг U2.3)

1. **Адаптер источника живых матчей** в Rust-опросе и в dev-мосте (`dev/bridge.ts`: новая база `livescore`). Нормализация в существующие статусы приложения: `scheduled` / `live` / `finished`, минута, счёт.
2. **Сопоставление турниров** — таблица соответствия десяти турниров (страна и название этапа LiveScore → лига приложения). **Сопоставление клубов** — через `clubKey` из `src/features/football/clubNames.ts` (сделан в U1.8), чтобы матч LiveScore связывался с клубом каталога и с матчем PitchAPI для перехода к деталям.
3. **Бережный опрос.** Расписание дня — при запуске, при смене местной даты и раз в час. Запрос «идущие» — раз в минуту и только когда идёт или вот-вот начнётся матч избранного турнира. Кэш, паузы при ошибках, `User-Agent` с названием приложения. Без матчей — ноль запросов.
4. **Запасной путь.** При ошибке или смене формата LiveScore — ESPN по лигам с матчами сегодня. Если не отвечают оба — последний известный счёт с отметкой времени. Минуту при отсутствии данных не выдумывать.
5. **Честность данных.** В строке источника: «Данные: LiveScore · обновлено 18:42». Неофициальность источника описать один раз, в «Настройки → Источники». Лента SportScore для этих экранов больше не нужна.
6. **Проверка до слияния.** В ближайший игровой день сверить LiveScore с табло трансляции: начало, гол, перерыв, финал. Замерить задержку и проверить матчи на границе суток UTC+9.
