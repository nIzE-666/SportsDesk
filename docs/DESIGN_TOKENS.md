# Токены оформления

Все цвета, размеры шрифта, скругления, отступы, высоты элементов управления, тени,
слои и длительности живут в `src/tokens.css`. Файл подключается в `src/main.tsx`
один раз, раньше остальных стилей. В стилях разделов не должно быть «сырых»
значений: только `var(--…)` из этого файла.

Оформление — «Спортивная обложка», шрифт Manrope. Тёмная тема задана на
`.app-root` по умолчанию, светлая — в `.app-root[data-scheme='light']`.

Часть страницы, которая остаётся тёмной в обеих темах, получает класс
`scheme-dark`: он задаёт те же значения, что и тёмная тема, не копируя их.
Так сделана сцена видеоплеера в «Смотреть».

## Цвета

### Поверхности, границы, текст

| Токен                    | Роль                                                |
| ------------------------ | --------------------------------------------------- |
| `--color-bg`             | фон страницы                                        |
| `--color-surface-1`      | панель                                              |
| `--color-surface-2`      | приподнятый элемент, строка, вкладка                |
| `--color-surface-3`      | всплывающая подсказка, меню, диалог, панель событий |
| `--color-border`         | обычная граница                                     |
| `--color-border-strong`  | граница у выбранного и активного элемента           |
| `--color-text`           | основной текст                                      |
| `--color-text-secondary` | вторичный текст                                     |
| `--color-text-tertiary`  | третичный текст, подписи                            |
| `--color-text-disabled`  | недоступный текст                                   |
| `--color-scrim`          | затемнение под диалогом и выдвижной панелью         |

### Акцент

| Токен                 | Роль                                                 |
| --------------------- | ---------------------------------------------------- |
| `--color-accent`      | активная вкладка, главная кнопка, полоса у заголовка |
| `--color-accent-soft` | фон с лёгкой примесью акцента                        |
| `--color-on-accent`   | текст и значки на акцентном фоне                     |

Турнир меняет только эти три токена. Поверхности, границы и текст одинаковы во
всех разделах. Без турнира («Сегодня», «Моё», настройки) действует нейтральный
акцент. Акценты заданы отдельными правилами `.app-root[data-theme='…']` и
`.app-root[data-scheme='light'][data-theme='…']`; список тем тот же, что в
`src/lib/navigationMetadata.ts`, плюс `f1` и `ucl`.

### Смысловые цвета

| Токен             | Роль                              |
| ----------------- | --------------------------------- |
| `--color-live`    | матч идёт сейчас                  |
| `--color-win`     | победа                            |
| `--color-draw`    | ничья                             |
| `--color-loss`    | поражение                         |
| `--color-warning` | предупреждение, устаревшие данные |
| `--color-error`   | ошибка                            |

### Графики и шины

- `--color-chart-1` … `--color-chart-8` — палитра графиков.
- `--color-team-home`, `--color-team-away` — цвета команд на странице матча и
  тактической доске: синий хозяева, оранжевый гости в обеих темах. Это ссылки на
  `--color-chart-1` и `--color-chart-2`, поэтому акцент турнира их не меняет.
- `--color-tyre-soft`, `--color-tyre-medium`, `--color-tyre-hard`,
  `--color-tyre-inter`, `--color-tyre-wet`, `--color-tyre-unknown` — цвета
  составов шин Формулы-1. Они настоящие и одинаковы в обеих темах.

Все цветовые токены — обычный hex или `rgb()`: так их читает проверка контраста.
Прозрачность задаётся через `rgb(… / …%)` в тенях.

## Витрина

«Телетрансляция». Он действует только внутри элемента с классом `showcase`:
остальные экраны и элементы кита не меняются. Переменные объявлены на
`.app-root` и переопределены в `.app-root[data-scheme='light']`; имена начинаются
с `--showcase-`.

`--showcase-font-display` — `'Exo 2 Variable'` с запасными Manrope и Segoe UI.
Шрифт подключён в `src/main.tsx` вместе с Manrope (`wght.css` и
`wght-italic.css`) и хранится в программе. Жирный курсив Exo 2 используется
только для заголовков-плашек, счёта и обратного отсчёта; остальной текст — Manrope.

Контраст посчитан по формуле WCAG для худшей пары «текст — поверхность»:

| Пара                                      | Тёмная тема | Светлая тема | Порог |
| ----------------------------------------- | ----------- | ------------ | ----- |
| основной текст к фону и панели            | 17,8 / 16,1 | 15,3 / 17,3  | 4,5   |
| вторичный текст к фону и панели           | 11,7 / 10,5 | 6,7 / 7,6    | 4,5   |
| акцент к фону и панели                    | 4,2 / 3,8   | 4,1 / 4,6    | 3     |
| текст на акценте                          | 4,6         | 4,6          | 4,5   |
| приглушённая линия к фону и панели        | 3,9 / 3,5   | 4,9 / 5,6    | 3     |
| «сейчас» к фону и панели                  | 6,6 / 6,0   | 5,4 / 6,1    | 4,5   |
| поребрик: красный к белому                | 4,3         | 5,4          | 3     |
| полотно трассы к панели                   | 3,2         | 4,7          | 3     |
| разметка поля к панели и тону             | 6,7 / 6,2   | 6,0 / 5,1    | 3     |
| обводка панели к панели                   | 3,8         | 3,8          | 3     |

Срез в цветах команд — украшение: текст на него не кладётся, а эмблемы стоят
на собственных плитках. Цвета команд приходят в SVG-атрибут `fill`; если цвета
нет, срез остаётся нейтральным.

## Шрифт

- `--font-family` — Manrope.
- `--text-12` — подписи и метки; меньше не используется.
- `--text-13` — вторичный текст.
- `--text-14` — основной текст и строки таблиц.
- `--text-16` — заголовок панели, названия команд в шапке матча.
- `--text-20` — заголовок крупного раздела.
- `--text-24` — заголовок страницы.
- `--text-32` — счёт и крупные числа.
- `--weight-regular`, `--weight-medium`, `--weight-semibold`, `--weight-bold` — 400, 500, 600, 700.
- `--line-body` — межстрочный интервал основного текста, `--line-heading` — заголовков.

Счёт, время и числовые колонки набираются цифрами одинаковой ширины
(`font-variant-numeric: tabular-nums`).

## Скругления, отступы, высоты

- `--radius-sm` 6px — метки и поля; `--radius-md` 10px — кнопки и строки;
  `--radius-lg` 14px — панели. `--radius-round` 999px — только круги и пилюли.
- Отступы: `--space-4`, `--space-8`, `--space-12`, `--space-16`, `--space-24`,
  `--space-32`, `--space-48`.
- Высоты элементов управления: `--control-sm` 28px, `--control-md` 36px,
  `--control-lg` 44px.

## Тени, слои, движение

- `--shadow-1` — приподнятый элемент, `--shadow-2` — всплывающая панель, диалог,
  выдвижная панель.
- Слои по возрастанию: `--layer-sticky` 6, `--layer-header` 10,
  `--layer-drawer` 30, `--layer-dialog` 100, `--layer-toast` 900,
  `--layer-tooltip` 950. Значения повторяют сегодняшние `z-index`.
- `--duration-hover` 120ms — наведение, `--duration-page` 180ms — смена вкладки
  и страницы; `--ease` — одна кривая для всех переходов.

## Контраст

`src/tokens.test.ts` читает `src/tokens.css` и считает контраст по формуле WCAG
для обеих тем и каждого акцента турнира:

- основной и вторичный текст — не ниже 4,5:1 к фону и каждой поверхности;
- третичный текст — не ниже 3:1 к ним же;
- акцент — не ниже 3:1 к фону, панели и приподнятому элементу;
- текст на акценте — не ниже 4,5:1 к акценту;
- смысловые цвета — не ниже 3:1 к фону и панели.

Значение меняется только ради этих порогов; каждое изменение записывается в
отчёт шага.

## Проверка стилей

`src/styleTokens.test.ts` обходит все `.css` под `src/`, кроме `src/tokens.css`,
и считает «сырые» цвета (hex, `rgb()`, `rgba()`, `hsl()`, `hsla()`, названия
цветов), `font-size` без одного из семи `--text-*` и `border-radius` без
`--radius-sm`, `--radius-md`, `--radius-lg`, `--radius-round`, `0` или `inherit`.
Список исключений пуст: любое такое значение валит проверку. Там же проверяется,
что ни в одном `.tsx` не осталось старых классов кнопок.
