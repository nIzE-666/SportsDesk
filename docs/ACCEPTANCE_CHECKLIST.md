# Ручная приёмка Windows-сборки (этап 0B)

Проверки, которые нельзя закрыть автотестами: они требуют установленного
приложения, реальной Windows-сессии или входа пользователя. Каждый пункт
отмечается результатом и датой. Провал — повод для задачи, а не для пропуска.

Сборка: `npm run tauri build` → установщик NSIS из `src-tauri/target/release/bundle/nsis`.
Перед началом сделайте резервную копию в «Настройки → Резервные копии».

## 1. Установка и первый запуск

- [ ] Установщик запускается без предупреждений, кроме SmartScreen для неподписанной сборки.
- [ ] После установки приложение открывается, тема и выбранный вид спорта сохранены.
- [ ] Повторный запуск ярлыка не открывает второе окно, а показывает уже запущенное.

## 2. Трей и фоновая работа

- [ ] Закрытие окна сворачивает приложение в трей (если режим трея включён).
- [ ] Меню трея: «Открыть» и «Выход» работают.
- [ ] После «Выход» процесса SportsDesk нет в диспетчере задач.

## 3. Системные уведомления

- [ ] Тестовое уведомление из настроек приходит как toast Windows.
- [ ] Клик по toast открывает приложение на нужном матче или гонке.
- [ ] При включённом «Не беспокоить» Windows приложение не падает и не дублирует уведомления позже.

## 4. Сон и пробуждение

- [ ] Переведите компьютер в сон на 5+ минут во время live-матча.
- [ ] После пробуждения счёт обновляется в течение минуты, без ошибок в журнале.
- [ ] Пропущенные за время сна события не приходят пачкой старых уведомлений.

## 5. Восстановление из копии

- [ ] Восстановление полной копии меняет настройки и историю, приложение перезапускается.
- [ ] Отмена на шаге подтверждения ничего не меняет.
- [ ] Копия более новой версии отклоняется с подсказкой обновить приложение.

### Аварийное завершение во время восстановления

1. Запустите восстановление копии.
2. Сразу после подтверждения завершите `SportsDesk.exe` через диспетчер задач.
3. Запустите приложение снова.

- [ ] Приложение запускается и показывает сообщение о завершённом или отменённом восстановлении.
- [ ] Настройки и история соответствуют либо копии, либо состоянию до восстановления — без смеси.
- [ ] В папке данных не осталось `restore-journal.json`.
- [ ] Новая резервная копия создаётся без ошибок.

## 6. Kino

- [ ] «Настройки → Kino»: адрес API, Client ID и Client secret сохраняются.
- [ ] «Войти по коду устройства» показывает код; после подтверждения статус «Вход выполнен».
- [ ] После перезапуска приложения вход сохраняется.
- [ ] «Выйти» удаляет токены; повторный вход работает.
- [ ] Окно с плеером открывается, поток воспроизводится.

## 7. Обновление поверх предыдущей версии

- [ ] Установите предыдущую версию, настройте избранное и сделайте копию.
- [ ] Установите новую версию поверх: настройки, история и вход в Kino сохранены.
- [ ] Недоступный источник данных (выключенный интернет) показывает понятную ошибку, а не пустой экран.

## 8. Игры и атмосфера: звук

Звуки проверяет только человек с колонками или наушниками. В «Настройки → Игры и
атмосфера» включите «Короткие звуковые сигналы» и «Фоновый звук».

- [ ] После установки и после обновления фон не звучит сам, кнопка с динамиком в верхней панели не нажата.
- [ ] Кнопка включает плавное звучание: в футболе — стадион, в Формуле 1 — двигатель; повторные нажатия не накладывают второй звук.
- [ ] Смена вида спорта при включённом фоне плавно меняет звук; «Всегда стадион» или «Всегда двигатель» фиксирует выбор.
- [ ] Ползунок «Громкость фона» меняет громкость фона сразу, громкость сигналов от него не зависит.
- [ ] «Проверить рог» и «Показать праздник гола» звучат; рог не оглушает на максимуме громкости.
- [ ] Включите канал в «Онлайн-просмотре» со звуком: при «Остановить фон» фон выключается и объясняет почему, при «Приглушить фон» тише и возвращается после паузы видео.
- [ ] Закройте окно в трей при «Остановить фон»: звук прекращается и не возвращается при открытии окна из трея; при «Продолжать звучать» фон идёт.
- [ ] Сверните окно кнопкой «Свернуть»: поведение то же, что при скрытии в трей.
- [ ] «Выход» из меню трея и закрытие окна без трея прекращают звук сразу.
- [ ] В тихие часы рог гола и радио F1 не звучат; фон, включённый вручную, не прерывается.

## 9. Игры и атмосфера: клетчатый флаг и подиум

Настоящий подиум можно проверить только в гоночный уикенд при запущенном приложении.

- [ ] «Настройки → Игры и атмосфера → Показать клетчатый флаг»: флаг проезжает по экрану, появляется подиум с подписью «пример», брызги шампанского, карточка закрывается сама и крестиком.
- [ ] При уменьшенном движении («Спокойно, без частиц» или режим Windows) пример — статичная карточка без флага и брызг.
- [ ] Гонка или спринт идут при запущенном приложении (окно открыто на любом разделе): после публикации итогов Jolpica появляется флаг и подиум победителя и двух призёров, названия верные.
- [ ] До публикации итогов ничего не показывается, победитель не выбирается по текущему лидеру.
- [ ] Перезапуск приложения после гонки не повторяет флаг; запуск приложения уже после публикации итогов тоже не показывает флаг, но итоги есть в Центре событий.
- [ ] Закрытое в трей окно: после возврата флаг не всплывает задним числом.
- [ ] Выключенные «Праздновать новые голы и финиш» — флага нет, итоги всё равно попадают в Центр событий.

## 10. Игры: «Стартовые огни»

Проверяется на настоящем компьютере, потому что важны мышь, клавиатура и экран.

- [ ] В боковой панели есть «Игры»; при выключенном «Включить игры и атмосферу» пункта нет, а открытая страница сообщает, что игры выключены.
- [ ] Игра ничего не делает, пока вы не нажали пробел, Enter или не кликнули по полю.
- [ ] Огни зажигаются по одному, гаснут через случайное время; нажатие после погасания показывает время в миллисекундах, статистика и рекорд обновляются.
- [ ] Нажатие пока огни горят — «Фальстарт»; удержание пробела с самого начала попытки не даёт ни фальстарта, ни времени.
- [ ] Переключение на другое окно (Alt+Tab) или сворачивание во время попытки прерывает её, и она не попадает в статистику.
- [ ] Перезапуск приложения и восстановление из копии сохраняют лучшее время и статистику.
- [ ] Курсор, колёсико и боковые кнопки мыши (назад/вперёд) не ломают игру и не запускают попытку случайно.

## 11. Игры: «Угадай счёт»

Нужен будущий матч одного из пяти поддержанных чемпионатов.

- [ ] В карточке предстоящего матча есть панель «Угадай счёт · мой прогноз»; в матчах Лиги чемпионов, кубков и MLS её нет.
- [ ] Прогноз сохраняется, меняется и убирается до начала матча; после начала форма исчезает и сообщает, что прогноз закрыт.
- [ ] Матч без объявленного времени начала не принимает прогноз.
- [ ] Вкладка «Игры → Угадай счёт» показывает прогноз в списке, «Открыть матч» ведёт в карточку.
- [ ] После окончания матча при открытии карточки или «Проверить результаты» появляются итог основного времени и очки (3 / 1 / 0); повторная проверка не меняет сумму.
- [ ] Для матча, скрытого режимом без спойлеров, счёт и очки не видны ни в панели, ни во вкладке, ни в итогах.
- [ ] Перезапуск и восстановление из копии сохраняют прогнозы и очки.
